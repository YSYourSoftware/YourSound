# YourSound

As another entry of the [YourSoftware series](https://yoursoftware.org), YourSound is an open source sound engine, with a very permissive licence.

## Project Parts

- `core` - Core Engine, can easily be integrated into other projects.
- `factory` - Factory content.
- `standalone` - Standalone application.
- `plugin` - [CLAP](https://cleveraudio.org) plugin to use in DAWs.
- `libmgr` - Library manager frontend.
- `libtest` - Testing of player loading and interactions.
- `quicksample` - Quickly sample instruments.
